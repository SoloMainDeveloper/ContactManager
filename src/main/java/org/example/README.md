# Менеджер контактов

## Задача 1. Реализация взаимодействия с контактами

Вся группа действий доступных с контактами начинается после нажатия кнопки “Контакты”.
При нажатии данной кнопки появится дополнительное меню, реализующее следующие возможности:

1. Добавить - запрашиваем «имя контакта», а потом дополнительную информацию по порядку: номер телефона,
    пол, возраст - где можно будет вводить данные, пропустить поле, закончить добавление контакта;
2. Получить все - пользователь может получить все контакты. В рамках данной задачи, реализуются дополнительно:
   + Фильтрация - пользователь может выбрать какие контакты он хочет получить (фильтры по полу, возрасту)
   + Сортировка - пользователь может выбрать в каком порядке выводить контакты (в порядке убывания/возрастания возраста, в алфавитном порядке имени или наоборот)
3. Найти - возможность найти контакт по имени или номеру телефона;
Результатом 2-3 функций будет вывод кнопок-контактов, по нажатию на которые будут доступны функции для взаимодействия с самим контактом:
4. Изменить - показывается набор кнопок:
   + Имя - изменить имя контакта;
   + Телефон - изменить телефон контакта;
   + Пол - изменить пол контакта;
   + Возраст - изменить возраст контакта.
5. Блокировать - заблокировать/разблокировать контакт;
6. Удалить - после подтверждения пользователем намерения удалить, контакт удаляется из базы данных.
7. Информация - выводится полная информация о пользователе (номер, возраст, пол)
